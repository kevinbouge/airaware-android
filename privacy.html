AirAware Privacy Policy

Effective date: August 4, 2026

```
Privacy summary: AirAware does not use analytics, advertising identifiers, user accounts, telemetry, cloud synchronization, or remote configuration. Most data is processed and stored locally on the user's device.

1. Overview

This Privacy Policy explains how AirAware handles information when you use the AirAware Android application.

AirAware provides environmental information related to pollen, air quality, weather-based mold potential, ultraviolet conditions, nearby vegetation, and related environmental measurements.

AirAware does not use analytics, advertising identifiers, accounts, telemetry, cloud sync, or remote configuration.

2. Location information

AirAware requests only approximate foreground location. It does not request precise location or background location.

Coordinates are sent to Open-Meteo to retrieve local environmental data, including optional advanced measurements when available. This occurs only after the user accepts the location explanation or selects a manual location.

Manual map selections are saved locally on the device and are used to refresh environmental data for the selected coordinates.

AirAware does not maintain its own server-side location history.

3. OpenStreetMap and nearby vegetation

When the manual map picker is displayed, OpenStreetMap tile servers receive requests necessary to provide map tiles for the visible map area.

When the Nearby vegetation feature is used, the active latitude and longitude are sent to the configured OpenStreetMap Overpass API. These coordinates are used to request mapped vegetation and land-use features near the selected location.

AirAware does not send Personal Allergy Profile selections, notification settings, shared summaries, or purchase information to OpenStreetMap or the Overpass API.

4. Personal Allergy Profile

Personal Allergy Profile selections are stored locally on the user's device.

These selections are not sent to Open-Meteo, OpenStreetMap, RevenueCat, or any other environmental data provider.

AirAware uses these locally stored selections only to personalize environmental risk calculations and presentation within the app.

5. Purchases and RevenueCat

AirAware uses RevenueCat to manage AirAware Pro purchase entitlement. Google Play processes payments. AirAware does not directly receive, process, or store card or payment information.

RevenueCat may process information required to validate and manage purchases, including:

  • Anonymous application user identifiers
  • Purchase records
  • Product identifiers
  • Subscription or entitlement state
  • Device and application metadata required for billing operations

AirAware does not send RevenueCat:

  • Location coordinates
  • Environmental readings
  • Personal Allergy Profile selections
  • Nearby vegetation data
  • Shared summaries
  • Notification settings

6. Shared summaries

Shared summaries are generated locally and passed to the Android share sheet. AirAware does not upload these summaries.

Shared summaries never include:

  • Location coordinates
  • Raw provider JSON
  • Personal Allergy Profile factor lists

When the Android share sheet is used, the application selected by the user to receive the summary may handle that information according to its own privacy policy.

7. Android widgets

Android widgets display locally cached AirAware snapshot data.

Widgets do not independently contact Open-Meteo, do not include coordinates, and do not display Personal Allergy Profile selections. Widget data is not uploaded by AirAware.

Android launchers may capture, cache, or display widget content as part of normal Android system behavior.

Locked advanced widgets do not expose environmental data when AirAware Pro is unavailable.

8. Notifications

Notification permission is requested only if the user enables risk transition notifications in Settings.

AirAware does not request notification permission on first launch.

Notification preferences are stored locally and are not sent to environmental data providers or RevenueCat.

9. Permissions AirAware does not request

AirAware does not request access to:

  • Background location
  • Precise location
  • Contacts
  • Camera
  • Microphone
  • SMS messages
  • Call logs
  • Health permissions
  • Installed application inventory
  • Advertising identifiers

10. Local storage and cached data

AirAware stores application settings and operational data locally on the user's device. Depending on the features used, this may include:

  • Application settings
  • Cached environmental provider responses
  • Selected coordinates
  • Manual location selections
  • Personal Allergy Profile selections
  • Notification preferences
  • Cached widget snapshot data

AirAware does not operate a cloud account or server-side user profile for this information.

11. Data retention and deletion

Because AirAware has no account system and no server-side user profile, clearing the application's storage or uninstalling the application removes locally stored settings, cached provider responses, selected coordinates, Personal Allergy Profile selections, and other locally stored application data.

RevenueCat uses anonymous application user identifiers for purchase entitlement management. The Restore purchases feature remains available so eligible Google Play purchases can be recovered.

Data processed independently by Google Play, RevenueCat, Open-Meteo, OpenStreetMap, or an Overpass API provider is subject to the retention and deletion practices of those respective services.

12. Third-party services

AirAware may interact with the following third-party services:

  • Open-Meteo for weather, air-quality, pollen, and related environmental data.
  • OpenStreetMap for map tiles and mapped geographic information.
  • An OpenStreetMap Overpass API provider for nearby vegetation and land-use queries.
  • RevenueCat for purchase entitlement management.
  • Google Play for application distribution and payment processing.

These services may receive technical information such as IP addresses, request metadata, device or application metadata, and other information ordinarily transmitted when connecting to an internet service.

Their handling of information is governed by their respective privacy policies and terms.

13. Advertising, analytics, and sale of data

AirAware does not display advertising, use advertising identifiers, or use analytics or telemetry services.

AirAware does not sell personal information.

AirAware does not use personal information for behavioral advertising or cross-application tracking.

14. Children's privacy

AirAware is not designed to collect personal information from children. The application does not provide user accounts, social features, advertising, or direct messaging.

If you believe that a child has provided personal information through AirAware, contact the developer using the information below.

15. Security

AirAware minimizes data collection and stores personal configuration locally wherever possible.

No method of electronic storage or internet transmission is completely secure. AirAware therefore cannot guarantee absolute security, particularly for information transmitted to third-party environmental or purchase-management services.

16. Changes to this policy

This Privacy Policy may be updated when AirAware's features, data practices, third-party providers, or legal requirements change.

The effective date shown at the top of this page will be updated when a revised policy is published.
```
